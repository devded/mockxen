# MockXen 🌟

A beautiful, 100% client-side screenshot mockup generator with interactive 3D parallax tilt and ambient glow effects.

## Features

- **Multiple Frames**: macOS browser, MacBook Pro, and mobile viewports.
- **Customization**: Ambient blur glows, customizable gradients, and padding control.
- **Interactive 3D Tilt**: Mouse-tracking perspective hover effect.
- **Instant Export**: Export directly to high-quality PNG client-side.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
